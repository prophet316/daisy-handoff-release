# Code of conduct

Daisy Handoff is a small project, and I want it to stay a good place to ask for help and report problems.

## What I expect
- Be kind and patient, especially with people installing something like this for the first time.
- Assume good intent. Criticize the code or the idea, never the person.
- Keep it on topic: the installer, the connector, the worker and how people use them.
- Never post anyone's connector URL, keys, personal details or private messages, yours included.

## What isn't welcome
- Harassment, insults, slurs or personal attacks.
- Sexual language or imagery.
- Spam, self-promotion unrelated to the project, or trolling.
- Publishing someone else's private information without their permission.

## If something happens
Use GitHub's **Report content** option on the comment, issue or discussion, or GitHub's [report abuse form](https://github.com/contact/report-abuse). I'll read every report, and I may edit, hide or remove content, lock a thread, or block someone from the project. For a security problem, use **Security > Report a vulnerability** instead.

This applies in issues, discussions, pull requests and anywhere else you represent the project.
